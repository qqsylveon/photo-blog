# PHOTO JOURNAL

个人摄影与生活记录网站。用照片留住日常，也用几句话记下快门之外的生活。

**Nuxt 4 · Vue 3 · TypeScript · SQLite · Sharp · GSAP · Lenis · Canvas / WebGL**

## 能做什么

| 模块 | 主要功能 |
| --- | --- |
| 首页 | 自定义引言、逐字入场、呼吸动效与摄影集入口 |
| 摄影集 | 分类瀑布流、大图浏览、EXIF、查看次数；每张照片独立展示 |
| 关于我 | 个人资料与动态墙，支持文字、多图、话题和浏览量 |
| 管理后台 | 批量上传、重复检测、拖动排序、发布/撤回、分类、文案与头像编辑 |
| 主题与动效 | 跟随系统/深色/浅色，光圈与骑行转场，星空/荷塘背景，可关闭特效 |

**已支持本地持久化与动态公开/私密控制。** OSS/CDN、原图下载、评论和多用户暂未接入。

## 快速启动

```bash
git clone https://github.com/qqsylveon/photo-blog.git
cd photo-blog
npm ci
cp .env.example .env
npm run dev
```

- 网站：http://127.0.0.1:3000/
- 后台：http://127.0.0.1:3000/admin/login

首次从本机进入后台可创建唯一管理员，密码至少 12 个字符。没有默认账号密码。前后台请统一使用 `127.0.0.1`，避免 Cookie 因地址不同而不共享。

> 运行要求 Node.js ≥ 22.13。项目自带 Node 22，安装完整依赖后通过 `npm run ...` 使用；电脑全局 Node 20.18 可保留。生产运行时需另行满足版本要求。

想从空相册开始：在**第一次启动前**将 `.env` 中的 `JOURNAL_SEED` 改为 `false`。已有数据不会被该配置清空。

## 后台使用

| 操作 | 说明 |
| --- | --- |
| 添加照片 | 选择或拖入多张图片 → 分别编辑 → 发布；不生成组图或封面 |
| 上传限制 | JPEG / PNG / WebP，单张最大 25MB、5000 万像素，每次最多选择 100 张 |
| 发布动态 | 文字或图片均可，每条最多 9 张配图，可存草稿或设为私密 |
| 修改文案 | “文案设置”中编辑首页、关于我、作者名称与头像 |

原图私有保存，前台展示压缩后的 WebP 与白名单 EXIF。浏览量按同一访客、同一内容 **24 小时去重**，属于近似统计。

## 数据与部署

| 位置 | 内容 |
| --- | --- |
| `data/journal.sqlite` | 内容、账号、设置与浏览量 |
| `storage/private/` | 私有原图 |
| `storage/public/` | 展示图，仍经过媒体路由鉴权 |
| `.env` | 本机配置，不提交 Git |

**备份必须包含数据库和整个媒体目录。** `npm run backup` 只备份数据库；自定义数据目录时，脚本需显式加载相同环境配置。

项目包含后端，需部署为 Node 服务；不是纯静态站点。生产环境使用 HTTPS，保留数据目录，不能将 `storage/` 直接公开为静态目录。
